# Frequently Asked Questions: Zomato Reel & Food Video Feed

### 1. What is Zomato Reel & Food Video Feed?
Vertical video food exploration feed with infinite scroll, ImageKit CDN, and user interaction states.

### 2. What technology stack does it use?
Built with Node.js (Express, MongoDB Atlas), React / JavaScript, ImageKit CDN.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/48-zomato-reel-feed/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
