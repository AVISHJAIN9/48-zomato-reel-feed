# 14.18 Master Design Decisions Audit Log

This document records every foundational technical decision, architectural pattern, and library selection made across the **Zomato Reel Feed** codebase.

---

## Architecture & Engineering Decisions Matrix

| Decision Area | Chosen Option | Alternatives Considered | Deciding Factors | Trade-Off Accepted | Revisit When |
|---|---|---|---|---|---|
| **Database Engine** | **MongoDB (Mongoose)** | PostgreSQL, MySQL, DynamoDB, Redis, Cassandra | Native JSON alignment with Node.js, rapid schema evolution for dishes, atomic `$inc` operators. | No cross-collection relational integrity at DB level. | If application expands into transactional food order billing. |
| **Media Asset Pipeline** | **ImageKit.io Node SDK** | AWS S3 + CloudFront, Cloudinary, Local Disk Storage | Single lightweight SDK bundling cloud storage, automatic video optimization, and a global edge CDN. | Uploading via server buffers consumes temporary RAM. | When monthly video bandwidth egress exceeds 200GB (switch to S3 presigned URLs). |
| **Session Management** | **JWT in HTTP Cookies** | LocalStorage tokens, Redis server-side sessions | Eliminates XSS token extraction; stateless architecture enables zero-overhead horizontal autoscaling. | Cookie invalidation requires Redis blocklist for instant revocation. | If enterprise Single Sign-On (SSO) or immediate cross-device logouts are required. |
| **Password Security** | **BcryptJS (10 salt rounds)** | Argon2id, PBKDF2, Scrypt, Plain SHA-256 | Adaptive computational cost factor ($2^{10}$ iterations), automated 128-bit salting, universal compatibility. | Consumes ~70ms CPU time per login attempt. | If NIST standards officially deprecate bcrypt in favor of Argon2id. |
| **Frontend Framework** | **React 19 (Vite)** | Next.js, Vue 3, Svelte 5, Angular 19 | Concurrent rendering, declarative hooks (`useRef`, `useEffect`) providing low-level DOM video control. | Larger initial JavaScript bundle footprint than Svelte. | If public SEO indexing of video descriptions becomes a primary growth driver (SSR). |
| **Video Autoplay Engine** | **Native IntersectionObserver** | Scroll event listeners with `getBoundingClientRect`, Waypoints.js | Operates asynchronously off the main thread; eliminates layout thrashing and dropped frames during fast scrolling. | Requires multi-threshold tuning to avoid premature play/pause toggles. | If virtual list recycling (react-window) is introduced for feeds exceeding 500 items. |
| **Styling Architecture** | **Vanilla CSS Custom Tokens** | Tailwind CSS, Styled-Components, Emotion, MUI | Zero runtime JavaScript overhead, instant native dark-mode switching, hardware-accelerated animations. | Requires manual organization of class names and stylesheet files. | If engineering team scales beyond 5 frontend developers (migrate to Tailwind). |
| **File Upload Handling** | **Multer Memory Storage** | Multer Disk Storage, Busboy, S3 Presigned URLs | Enables immediate buffer forwarding to ImageKit without managing local disk cleanup jobs on ephemeral containers. | Spikes Node.js process heap memory during concurrent 50MB+ uploads. | When concurrent partner uploads exceed 10 simultaneous streams. |
| **Like & Save Counters** | **Denormalized Counters (`$inc`)** | On-the-fly `$lookup` counting, Embedded User ID arrays | $O(1)$ read performance when hydrating the global feed; avoids hitting MongoDB 16MB document size limit. | Potential transient drift if an application crash occurs between join record write and counter update. | When concurrent write contention on a single viral reel exceeds 500 writes/sec (buffer in Redis). |
| **Backend Architecture** | **Layered Modular Monolith** | Microservices, AWS Lambda Serverless | Zero network serialization latency between layers; rapid feature iteration; unified deployment. | Single fatal unhandled exception can take down all application endpoints. | When team expands into dedicated sub-teams (e.g. Media Team vs Recommendation Team). |
| **Client Routing** | **React Router DOM v7** | TanStack Router, Wouter, Page.js | Declarative `<Routes>` tree, native `NavLink` active tab styling, mature community ecosystem. | Slightly larger bundle size than micro-routers like Wouter. | Never; standard industry framework. |
| **AI Integration Phase** | **Deferred to Phase 2 (Gemini)** | Custom Convolutional Vision Model (ResNet) | Avoided premature $50k+ GPU training expenses; pre-trained multimodal Gemini API provides instant dish tagging at fractions of a cent. | Initial MVP lacks automated allergen and ingredient tagging. | When onboarding >50 restaurant partners with high-volume video catalogs. |
