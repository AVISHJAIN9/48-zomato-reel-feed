# Step 12: Technical Terms & Domain Glossary

This glossary defines technical terms, design patterns, and domain concepts used throughout the **Zomato Reel Feed** architecture.

---

## Technical Glossary

* **Adaptive Bitrate Streaming (ABR):** A video delivery technique (like HLS or DASH) where a video is encoded at multiple bitrates, and the client dynamically selects the optimal stream based on current network bandwidth and CPU capacity.
* **Autoplay Policy:** Security and user-experience rules enforced by modern web browsers (Chrome, Safari) that block unmuted programmatic video playback unless the user has actively interacted with the page.
* **Atomic Operator (`$inc`):** A database operation that completes in a single, indivisible step. In MongoDB, `$inc` directly increments or decrements a numeric field without reading the document into application memory first, preventing race conditions.
* **Bcrypt:** An adaptive, password-hashing function based on the Blowfish cipher. It incorporates a salt to protect against rainbow table attacks and an adjustable work factor (salt rounds) to slow down brute-force hardware cracking.
* **BSON (Binary JSON):** A binary-encoded serialization format used by MongoDB to store documents and execute remote procedure calls, supporting data types like Date, ObjectId, and binary buffers.
* **Buffer (Node.js):** A global Node.js class representing a raw chunk of binary memory allocated outside V8's garbage-collected heap, used to process streams, network packets, and file uploads.
* **Cache-Aside Pattern:** A caching strategy where the application first checks the cache (e.g. Redis) for requested data. On a cache miss, it reads from the primary database, populates the cache, and returns the result to the client.
* **Collection Scan (`COLLSCAN`):** A performance-degrading database execution state where MongoDB must inspect every document in a collection because no matching index exists to satisfy the query filter.
* **Compound Unique Index:** An index spanning multiple fields (e.g. `{ user: 1, food: 1 }`) that enforces uniqueness on the combination of those fields, preventing duplicate relationship records.
* **Cross-Origin Resource Sharing (CORS):** A W3C security mechanism allowing a web server to declare which external origins (e.g. `http://localhost:5173`) are permitted to access its resources and transmit credentials (cookies).
* **Denormalization:** The practice of storing redundant or precomputed data (such as `likeCount` directly inside the `Food` document) to optimize read performance and avoid expensive join queries.
* **DOM (Document Object Model):** The tree-structured in-memory representation of an HTML document rendered by the browser.
* **Fiber (React Reconciliation):** React's internal architecture that enables cooperative multitasking, splitting rendering work into incremental chunks that can be paused, aborted, or prioritized.
* **HLS (HTTP Live Streaming):** An adaptive streaming communications protocol developed by Apple that slices video into small HTTP-based file chunks (`.ts` or `.m4s`) indexed by an `.m3u8` playlist.
* **HTTP-Only Cookie:** A cookie attribute that instructs the browser that the cookie should not be accessible via client-side scripts (`document.cookie`), neutralizing Cross-Site Scripting (XSS) token theft.
* **Idempotency:** A property of certain HTTP methods (`GET`, `PUT`, `DELETE`) where making multiple identical requests produces the exact same server state as making a single request.
* **IntersectionObserver:** A native browser API that provides a way to asynchronously observe changes in the intersection of a target element with an ancestor element or top-level viewport.
* **JSON Web Token (JWT):** An open standard (RFC 7519) that defines a compact, self-contained way for securely transmitting information between parties as a digitally signed JSON object.
* **Layout Thrashing:** A web performance bottleneck caused by repeatedly reading and writing DOM geometry properties in the same frame, forcing the browser to perform synchronous recalculations and dropping frame rates below 60fps.
* **MERN Stack:** A full-stack web development technology suite consisting of MongoDB (Database), Express (Backend Framework), React (Frontend Library), and Node.js (Runtime).
* **Mongoose:** An Object Data Modeling (ODM) library for MongoDB and Node.js that provides schema validation, casting, business logic hooks, and query building.
* **Multer:** A Node.js middleware for handling `multipart/form-data`, primarily used for parsing and streaming file uploads.
* **Object URL (`blob:`):** A pseudo-URL generated by the browser's `URL.createObjectURL()` pointing directly to binary data stored in client memory, enabling instant video previews.
* **OWASP Top 10:** A standard awareness document representing a broad consensus on the most critical security risks to web applications.
* **Populate (Mongoose):** A Mongoose method that automatically replaces referenced ObjectIds in a document with the actual populated documents from another collection.
* **Presigned URL:** A time-limited, cryptographically signed URL that grants client browsers permission to upload or download files directly to cloud object storage (AWS S3 or ImageKit) without routing binaries through an API server.
* **Rate Limiting:** A network control strategy that caps the number of requests a client IP or authenticated user can dispatch within a specified time window to prevent denial-of-service and brute-force abuse.
* **Salt Rounds:** The logarithmic cost factor in bcrypt that determines the number of hashing rounds executed ($2^{\text{rounds}}$).
* **Stateless Architecture:** An application design model where the server retains no client session state between requests; every incoming request contains all information necessary to authenticate and process it.
* **Time to First Byte (TTFB):** The elapsed time from client HTTP request dispatch to the arrival of the first byte of response data from the server or CDN.
* **Vite:** A next-generation frontend development and build tool that leverages native browser ES modules for instant hot module replacement and Rollup for production builds.
* **XSS (Cross-Site Scripting):** A security vulnerability where an attacker injects malicious client-side JavaScript into a trusted web application.
